# Contributing

- One addition per pull request.
- Format: `- [Name](link) - Description ending with a period.` Keep descriptions factual and short; no marketing language.
- Alphabetical order within each section.
- Only projects that are public, working and relevant to in-app browsers (or to tools whose visitors arrive through them).
- Shortener and link-in-bio maintainers: if your project adds a built-in in-app browser escape option or plugin, open a PR noting it — we'll mark it.
- Cheat sheet changes need a device test: app + version, OS + version, technique, result. Open an issue if unsure.
